# 🗑️ Street Cleaner

A small 2D driving game made with **Unity and C#**, developed as part of my journey learning game development.

The project started from the **Delivery Dash** project in the GameDev.tv "Complete C# Unity 2D Game Development" course. I used the course project as a starting point and then modified and expanded the gameplay to create my own garbage-collection themed game.

## 🎮 About the Game

In **Street Cleaner**, you drive around the city collecting garbage before time runs out.

Manage your **fuel** and **time** carefully while trying to collect as much trash as possible.

### Core Gameplay

* 🚗 Drive around the map
* 🗑️ Collect garbage
* ⛽ Manage your fuel
* ⏱️ Race against the clock
* 🏆 Collect all garbages before time runs out
* 💥 Lose the game if you run out of time or fuel
